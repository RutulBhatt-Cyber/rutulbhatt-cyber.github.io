# Rutul Bhatt — Portfolio

A single-page portfolio for GitHub Pages.

## Publish
1. Create a public repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages** and deploy from the `main` branch.
4. Visit `https://YOURUSERNAME.github.io`.

Replace the LinkedIn and GitHub placeholder links in `index.html` with your profiles.
